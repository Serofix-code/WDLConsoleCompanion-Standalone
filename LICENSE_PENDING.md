# License choice required

The project owner has not selected an open-source license. No `LICENSE` file is included because choosing legal terms on the owner's behalf would be inappropriate.

Before the first public source release, the maintainer should select a license compatible with the intended contribution and redistribution model. Until then, normal copyright rules apply and public users do not automatically receive permission to copy, modify, or redistribute the code.

Contributors should not submit code copied from projects with incompatible or unknown licenses. Third-party code and data must retain required attribution and license notices.
