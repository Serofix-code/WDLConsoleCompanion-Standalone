# Build compatibility

Every research record lists observed builds. Preferred identity fields are platform, distribution, module filename, module SHA-256, observation date, and notes.

The current observed session uses the Steam PC DX11 module `DuniaDemo_clang_64_dx11.dll`. Its exact SHA-256 has not yet been recorded, so broad compatibility is **unknown**. DX11, DX12, plus, Ubisoft Connect, Epic, and Steam builds must be treated separately until hashes and signatures are tested.

Never upload game modules. Contributors should calculate hashes locally and submit only the digest.
